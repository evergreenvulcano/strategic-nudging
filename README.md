# strategic-nudging

> A playbook for semantic transmission towards natural forces through an expansion-adjacent communicational framework.

---

## What This Is

This repository is a **living framework** for transforming consultant insights into a semantic form that a receiver can wear without loss of value — without crossing their sovereign boundaries, without flattening their context, without diminishing their capacity.

The core rule: **language is never corrective. It is always capacity-expanding.**

---

## How It Works

Cases are processed through a **pseudonym layer**. No real names, company names, product names, or identifying markers are stored in this repository. Every subject becomes a codename. Every domain becomes a metaphor. Every interaction is translated into the framework's language before it enters the repository.

The real-to-pseudonym mapping is maintained **locally**, outside version control. The repository only ever knows the pseudonyms.

This forces two disciplines simultaneously:
1. **Conceptual abstraction** — the insights must generalize enough to survive translation.
2. **Semantic protection** — the subject's context is never publicly exposed.

## The Language

This framework does not use the word **problem**.  
It does not say **you are missing**.  
It does not imply **you need to learn**.

It says: **the empire now requires new control rooms.**

Not because the builder is insufficient. But because what has been built is large enough to demand new forms of mastery.
